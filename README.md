# BoysNet Importados — Catálogo Mayorista

Catálogo web mayorista para **BoysNet Importados** (`@casaboysnet` · Encarnación, Paraguay) con precios en dólares (USD), filtros por categoría y marca, y armado de lista para consulta directa por WhatsApp.

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación y compilación

```bash
npm run lint
npm run build
```
